# aura-bebe
Application pour suivi de grossesse et bébé 

Les fichiers du site sont dans `public/`. Netlify publie directement ce dossier,
sans commande de compilation, grâce à `netlify.toml`.

Pour modifier l’application, modifier les fichiers de `public/` ; l’archive
`aura-bebe-site.zip` est conservée comme source d’origine et n’est pas publiée.
